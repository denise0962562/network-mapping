# Report chart fonts

`ReportChinese.ttf` is Droid Sans Fallback (Google, Apache License 2.0), used
for the fixed Chinese chart title, status legend and empty-state text.
`ReportLatin.ttf` is Noto Sans Regular (Google, SIL Open Font License 1.1),
used for dates and numeric axes. The fonts are embedded into the server binary;
rendering requires no host font packages or display server.

See `Apache-2.0.txt` and `Noto-LICENSE.txt` for license and attribution details.
